01

Introducción

Este documento define las especificaciones técnicas de exportación para todas las fotografías de producto destinadas al sitio web de 1927. Su propósito es garantizar consistencia visual, rendimiento óptimo de carga y calidad de imagen en todos los dispositivos. No cubre dirección creativa ni estilos visuales — únicamente los parámetros técnicos de entrega.

Importante: Este manual aplica exclusivamente a las imágenes destinadas al sitio web. Los archivos RAW deben entregarse siempre como respaldo independiente.

04

Nomenclatura de archivos

Todos los archivos deben nombrarse siguiendo esta convención sin excepción. La nomenclatura correcta es necesaria para el SEO del sitio y para la organización del Media Library de WordPress.

[SKU Padre] — [# posición en galería].jpg
M1055-H-GREY-1.jpg ← posición 1
M1055-H-GREY-2.jpg ← posición 2
M1055-H-GREY-3.jpg ← posición 3
M1055-H-GREY-4.jpg ← posición 4
M1055-H-GREY-5.jpg ← posición 5
M1055-H-GREY-6.jpg ← posición 6
Regla Correcto Incorrecto
Separadores Guiones: M1055-H-GREY-1 Espacios, guiones bajos, puntos
Extensión .jpg (minúsculas) .JPEG .JPG .Jpg
SKU Exactamente como en el sistema Abreviaciones o variantes libres
Posición Número consecutivo desde 1 Letras, palabras descriptivas
05

Entrega de archivos

Cada sesión debe entregarse en dos carpetas separadas: archivos RAW para respaldo y archivos JPEG listos para producción web.

📁 M1055-H-GREY/
📁 RAW/
M1055-H-GREY-1.CR3
M1055-H-GREY-2.CR3
M1055-H-GREY-n.CR3
📁 JPEG/
M1055-H-GREY-1.jpg
M1055-H-GREY-2.jpg
M1055-H-GREY-n.jpg
  • Una carpeta por SKU/variante. No mezclar productos o colorways en la misma carpeta.
  • RAW siempre incluido. Los archivos RAW son el respaldo maestro para posibles re-ediciones.
  • JPEG ya renombrado. Los archivos JPEG deben llegar con la nomenclatura final correcta, no con el nombre de la cámara.
  • Sin ediciones destructivas en RAW. Los RAW no deben tener ajustes horneados irreversibles.
  • Verificar perfil de color antes de exportar. Confirmar que el espacio de color sea sRGB en la configuración de exportación de Lightroom o Photoshop.
